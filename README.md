# Locations List
An app to test the location URL handling. Focused on the Wikipedia app.

## Building and Running

The app is built and tested with Xcode 26.3. There are no other dependencies.

## Project Structure

Data source: [LocationsAPI.swift](Locations%20List/LocationsAPI.swift)
URL generator: [Wikipedia.swift](Locations%20List/Wikipedia.swift)
The main container view: [tLocationsListContainerView.swiftt](Locations%20List/Views/LocationsListContainerView.swift)
Custom coordinates form: [CustomLocationView.swift](Locations%20List/Views/CustomLocationView.swift)
